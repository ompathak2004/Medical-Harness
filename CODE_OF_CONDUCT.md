# Community code of conduct

OpenMed welcomes contributors with different backgrounds and levels of experience. Be respectful, assume good intent, and discuss ideas and code without personal attacks, harassment, or discrimination.

Because this is a health-related project, use synthetic examples in public discussions. Do not post someone else's health information, API keys, or content that presents unverified medical advice as a diagnosis.

Maintainers may edit, hide, or remove content that violates these expectations and may restrict repeat offenders from participating. Report conduct concerns privately to the repository owner through their GitHub profile. Report security issues through [SECURITY.md](SECURITY.md).
